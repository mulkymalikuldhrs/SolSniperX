## Overview

**SolSniperX v3.3.0 (Ultimate Intelligence Upgrade)** is a professional-grade Solana memecoin sniper bot. It combines real-time mempool monitoring, LLM-powered AI analysis, and multi-layered anti-rug protection to provide a fully autonomous trading experience. Engineered for speed and reliability, it operates with 100% real-world data integration.

## Features

### Token Sniping Engine
- Real-time monitoring of new Solana token launches via Raydium, Pump.fun, and other DEXs
- Sub-second trade execution on the Solana blockchain
- Configurable buy/sell parameters (amount, slippage, gas priority)
- Multi-token concurrent sniping support

### Anti-Rug Pull Protection
- Liquidity lock verification
- Mint authority renunciation checks
- Holder distribution analysis (whale detection)
- Contract source code scanning for suspicious patterns
- Dev wallet tracking and abnormal activity alerts
- **RugCheck.xyz Full API Integration**

### Smart Filtering
- Customizable token filters (name, symbol, metadata patterns)
- **Social Metadata Integration** (Twitter, Telegram, Websites)
- Liquidity pool minimum thresholds
- Age-based filtering to avoid stale tokens

### Trade Management
- Automatic take-profit and stop-loss execution
- **Multiple Take-Profit Tiers**
- **Trailing Stop-Loss**
- **VWAP Momentum Filter**
- Portfolio tracking with P&L calculations
- Real-time transaction logging

## Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/mulkymalikuldhrs/SolSniperX.git
cd SolSniperX

# Backend Setup
cd backend
pip install -r requirements.txt
cp .env.example .env # Configure your SOLANA_PRIVATE_KEY and API keys

# Frontend Setup
cd ../frontend
pnpm install
cp .env.example .env
```

### Configuration

Edit `auto_trader_config.json` or use the Settings page in the Dashboard to configure your trading parameters.

### Running

```bash
# Start the system
./start_dev.sh
```
